# Arknight_nogambling

## 1.说明
因为PRTS网站的抽卡的沉浸感与还原感不够，所以采用AI制作了本项目。卡池的概率计算方法参考了PRTS网站的抽卡模拟器。
尽量还原了界面ui，音乐音效，开包动画，10连抽的结果展示，单抽时干员登场的背景和语音等内容。
目前收录 5 个卡池，首页左侧可直接切换；手机竖屏时在底部横向滑动选择。

| 卡池 | 国服原始开放时间 | 六星 UP |
| --- | --- | --- |
| 将雪投火 | 2026.11.01—11.15 | 塔露拉（限定）、冻河 |
| 劫尽古今 | 2026.02.10—02.24 | 望（限定）、赤刃明霄陈 |
| 承诺 | 2026.05.01—05.15 | 凯尔希·思衡托（限定）、可露希尔 |
| 车辙与风的归所 | 2026.08.01—08.15 | 予愿安洁莉娜（限定）、珊比 |
| 泰拉饭，呜呼，泰拉饭 | 2024.09.02—09.16 | 玛露西尔（迷宫饭联动） |

卡池保留各自当期的完整干员名单，共涉及 215 名干员。每池独立保存六星计数、首次十抽与保底进度，干员收集及寻访记录共用。原“将雪投火”存档可继续使用。四个常规限定池各可在 300 次寻访后，从“寻访详情与概率”领取一次当期限定干员；迷宫饭为前 120 次必得玛露西尔（仅一次，提前获得即达成），首次获得一位 UP 五星后，下一位五星必为另一位（仅一次）。

基础抽样保留本项目已有的 PRTS 权重实现：六星递增权重整体归一化，与官方公告的标称概率存在差异，没有第 99 抽必出的硬保底；详情页面可查看说明和完整名单。迷宫饭的一次性保底与五星保护按该期原始规则处理。未实现寻访数据契约交换所。

五个卡池首页均使用当期客户端界面包导出的布局、Sprite 图层、锚点、裁切和姓名牌。新增三个 2026 限定池使用原始入场关键帧的稳定画面；迷宫饭使用 2024 年专用界面包及其共享界面资源。标题采用原版图片，并区分材质颜色和特效控制通道。暂未重放完整入场转场和 Unity 粒子、流光着色器。

## 2.使用方式

可以直接[在线体验](https://zrjzsyyx.github.io/arknights_nogambing/)，也可以下载到本地运行：

1. [下载项目压缩包](https://github.com/zrjzsyyx/arknights_nogambing/archive/refs/heads/main.zip)，完整解压后，双击文件夹里的 `index.html`，用浏览器打开。
2. 选择单抽或十连。开包时，按住右侧的拉链头向左拖动，也可以点击按钮直接开包。
3. 干员登场时会播放日语报到语音，并显示中文字幕。十连可以逐个查看干员，也可以跳过动画，直接看全部结果。

下载后可以断网使用，不需要安装额外的软件或启动服务器。请保留整个项目文件夹，单独复制 `index.html` 无法运行。

如果没有声音，先点击页面，再检查声音按钮和设置里的音量。抽卡记录保存在当前浏览器中，换浏览器或清理浏览器数据后，记录可能会丢失。

开发时运行 `npm ci`、`npm run dev`；修改后用 `npm run build` 更新双击运行所需的离线包，`npm test` 检查抽样、保底、素材和离线数据。可选浏览器检查：安装 Python Playwright 与 Chromium 后运行 `python qa_pools.py`，覆盖 5 池切换、抽卡、语音、4 种屏幕尺寸及断网存档恢复。

素材维护：`python fetch_pools.py` 同步卡池名单、立绘、界面素材和阵营图标，再运行 `python fetch_result_assets.py`、`python fetch_recruitment_voices.py` 补齐头像和报到语音，最后重新构建。原始配置缓存于忽略的 `research/`，运行成品无需联网。

原版首页的导出工具为 `export_pool_ui.py`，与 `export_official_ui.py` 一样需要 UnityPy 和 LZ4AK 解码模块；可用 `--tools` 指定这些 Python 模块所在目录。工具按校验和固定的历史资源版本下载并验证原始界面包；每池 `dist/assets/official/pools/*/prefab.json` 记录原始文件、布局与图片校验值。
